# GameX · 大学生桌面模拟器

回到 2012 年，从宿舍里的一台电脑开始，度过属于自己的大学第一学期。

这是可操作、可存档、可完成学期结算的 Web 游戏。没有强制主线：上课、学习、开黑、聊天、恋爱、社团、兼职和休息，都在争夺同一份时间与精力。

## 启动

推荐 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

打开终端输出的本地地址，默认是 `http://localhost:5173`。如果默认 npm 源无法访问，可使用：

```bash
npm install --registry=https://registry.npmmirror.com
```

生产构建与预览：

```bash
npm run build
npm run preview
```

生产版本通过 HTTPS 或 localhost 首次加载并完成资源缓存后，支持断网刷新与继续游玩。开发服务器用于开发和热更新，需要保持运行。运行不调用任何大模型或游戏后端 API。

## 怎么玩

1. 填写姓名、性别、专业和故事种子，创建新生档案。
2. 从 Windows 7 桌面的便笺查看日期和资源；QQ2012 主面板默认打开，双击联系人开始聊天。
3. 在课程表里按时上课，在学习中心完成每周作业、间隔复习和专业练习。
4. 在 QQ 回复消息，从聊天工具栏“人物关系与邀约”安排散步、喝热饮或发展关系。点击好友的空间图标可访问其 QQ 空间。
5. 打开英雄联盟，点击红色 PLAY，选择位置、早期英雄和队友。匹配等待时可以聊天，正式对局需连续做出对线、资源与团战三个阶段的决策；盒子提供战绩与出装资料。
6. 在 Internet Explorer 的勤工助学中心接受兼职，在人人网发布新鲜事、点赞评论，在 QQ 空间写说说、查看日志、相册与留言。
7. 在“我的校园 → 生活计划”分配背景日的 8 小时课余时间。点击便笺“结束今天”或开始菜单“关机”，睡觉并推进到下一关键日。
8. 走完 16 周后查看教务系统：真实成绩、学分、奖学金资格、称号、关系、经济与回忆都会进入学期档案。

现实时间不会自动消耗游戏时间。拖动窗口标题栏移动，双击标题栏最大化，拖动右下角缩放，通过任务栏切换或最小化。小屏幕可通过开始菜单切换应用。

游戏每次操作后自动存档；`Ctrl + S` 也可以手动保存。控制面板支持 JSON 导出、导入和上次备份恢复。存档与历史榜单存在当前浏览器中，换浏览器、换域名或清理网站数据不会自动迁移，请先导出。此次界面更新沿用原有 v1 存档。

## 测试

```bash
npm test
npm run simulate
npm run test:e2e
```

- Vitest：时间、成本、学习、考试、关系、事件、承诺、匹配、种子复现、存档、称号、榜单与学期结算；两个专业各跑学习、游戏、恋爱、社交、兼职、均衡和随意七种策略。
- Playwright：角色创建、两个专业、多窗口、QQ 独立聊天、英雄选择与竞技、盒子资料、人人网、QQ空间、事件、兼职、日记、刷新恢复、完整学期、榜单、小屏布局、生产断网与缓存升级。
- 浏览器测试默认使用本机已安装的 Google Chrome。没有 Chrome 时，可安装 Playwright Chromium 并在 `playwright.config.ts` 中去掉 `channel: 'chrome'`。
- `npm run test:e2e` 会先构建，再使用 5173 开发端口与 4173 生产预览端口；已有对应服务可复用。
- 自动化报告位于 `playwright-report/`；实际界面截图在 `artifacts/`。两者不进入源代码提交。

## 当前边界与后续建议

- 本期可以完整游玩一个秋季学期。四年八学期、毕业结局、云存档、联网排行榜、大模型接入与其他竞技游戏尚未开放；状态中的学期编号和适配器接口用于后续扩展。
- 班级群为公告式聚合消息，首版不提供自由群聊。自由文本聊天由本地规则回应，不理解任意自然语言含义；不会声称能像语言模型一样聊天。
- 专业题库目前每个专业六道，循环出题。首版以基础策略和学习反馈为主，尚未提供开放式代码执行、真实三维解剖或复杂病例模拟。
- 竞技是三阶段策略模拟，后台训练只计总战绩，详细战术仅记录手动对局；不提供实时操作类 MOBA。
- 存档导入限制 5 MB，历史榜单保存最近 100 份学期档案。存档文件不包含其他局的排行榜；数据校验用于防损坏，不提供防作弊能力。
- 世界行为经过自动化验证，但未经过长周期真实玩家试玩和用户人工验收。后续宜扩展题库、替代失败事件分支、人物对话差异与长时间平衡性测试。

校园与人物为虚构。桌面与软件界面按 Windows 7 和 2012 年真实软件重建，具体素材来源见参考文档；软件名称、标识和引用图像的相关权利归原权利方。软件与系统快捷图标直接使用原始图片，图标源地址、摘要与原生尺寸见 `public/period-assets/icons/sources.json`；人物头像与策略地图由项目内 SVG / CSS 绘制，通用操作图标使用 Lucide。游戏不连接真实 QQ、人人网或 Riot 账号。
