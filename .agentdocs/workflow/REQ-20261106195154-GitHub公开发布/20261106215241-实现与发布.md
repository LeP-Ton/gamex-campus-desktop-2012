## 决策与变更

- 用户已明确选择公开源码和 GitHub Pages，目标账号与仓库名已在选项中给出。通过 CLI 创建公开仓库并启用 Pages workflow 模式；连接工具不提供新建仓库和 Pages 设置能力。
- `src/lib/assets.ts` 统一处理 Vite 基础路径；桌面、程序图标、英雄、装备、原画、地图和 Worker 注册使用该入口。CSS 与 HTML 的静态资源由 Vite 按 base 转换。
- `vite.config.ts` 按实际 base 与 outDir 生成离线文件清单，缓存仅匹配当前版本。按项目路径生成缓存前缀，只在根部署时迁移旧的十二位散列缓存，避免删除同域其他项目数据。
- `.github/workflows/deploy.yml` 在 main 推送时运行规则测试并发布 Pages，Node.js 22，动作版本已通过 GitHub 官方 release API 核对。
- `build:pages` 生成 `dist-pages/`，本地浏览器测试分别覆盖根目录与 GitHub 项目路径；不改游戏数值或存档结构。
