## 用户要求与原因

用户指出桌面图标仍为手绘，要求直接使用真实软件原图标或网上找到的高清图标。此前 `PeriodIcon.tsx` 的简化 SVG 不满足此项验收，尤其人人网与多玩盒子采用了错误的标识。本阶段移除这些重绘图形，改用可追溯的真实图像资源，覆盖桌面、开始菜单、任务栏、窗口标题及应用内共用入口。

## 当前方案

- Windows 7 使用从原系统资源导出的 ICO，优先按原生 16、32、48、256 像素帧输出透明 PNG，不将低分辨率素材放大后冒充高清图。
- 开始按钮使用原版三态图片，替换此前的 CSS 圆球和重绘 Windows 旗帜。
- 真实软件使用官网或历史资源存档的原标识；虚构校园应用复用 Windows 7 原始文件、文件夹与系统工具图标。
- 素材放在 `public/period-assets/icons/`，来源、原始分辨率及摘要随清单记录；运行时读取本地文件并纳入已有离线缓存。
