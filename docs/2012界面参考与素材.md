## 采用的时代特征

Windows 7 使用默认 Harmony 蓝色壁纸、彩色开始圆球、双栏开始菜单、约 40 像素任务栏、Aero 边框与窗口按钮、传统快捷方式、模拟时钟和便笺。桌面不再以现代全屏仪表板为主体。

QQ2012 使用窄主面板、蓝色皮肤、头像/签名/等级、好友/群/最近联系人标签、可展开分组、独立聊天窗口、蓝绿姓名与时间文本消息、底部输入区和“关闭(C) / 发送(S)”按钮。游戏内资料与邀约放在好友资料侧栏。

人人网采用蓝白顶栏、左侧实名资料与应用、中央新鲜事及发布器、右侧好友推荐和访客模块。QQ空间作为独立应用，使用六代空间的个人主页、蓝天风格装扮、模块化栏目、说说、日志、相册、留言板和访客区域。

英雄联盟以旧 AIR 客户端为参考，保留经典标识、红色 PLAY、暗蓝金属框、早期英雄头像、免费英雄、召唤师资料、S2 排位积分、英雄选择和战绩。对局仍为既有三阶段策略模拟，增加旧峡谷风格地图、双方位置标记、英雄栏、技能栏、装备和小地图。多玩盒子提供独立战绩查询、英雄资料、出装攻略和资源提示设置。

## 运行素材

所有实际使用的位图在 `public/period-assets/`，运行时不访问这些外部来源。

- `win7-harmony.jpg`：Windows 7 Harmony 经典壁纸，使用[原始 1920×1200 图像](https://files.enderman.ch/wallpapers/windows-7/img0.jpg)。最初从[公开图像镜像](https://i.pinimg.com/originals/2b/aa/39/2baa39f8d28ab0ed4acd77b397019fdc.jpg)取得低分辨率版本，完整原图下载后已替换。
- `Ashe.png` 等十张头像、`item-*.png`：Riot Data Dragon `0.151.2` 资源，例如 [早期艾希头像](https://ddragon.leagueoflegends.com/cdn/0.151.2/img/champion/Ashe.png)、[无尽之刃](https://ddragon.leagueoflegends.com/cdn/0.151.2/img/item/3031.png)。此版本作为早期图像资源基准，不将其等同于 2012-09-03 当日的完整国服版本。
- `ashe-2012.jpg`：[2012-05-18 PBE 更新资料](https://www.surrenderat20.net/2012/05/5-18-pbe-update-darius-ratios-skin-arts.html)中的艾希原画，仅作为大厅展示素材。
- `summoners-rift.svg`：项目内按旧版召唤师峡谷的三路、河道、树林和蓝紫基地结构绘制的策略地图；不是实际三维游戏场景截图。
- `PeriodIcon.tsx`：读取 `icons/` 中的真实系统与软件图标，按显示尺寸选择原生帧。此前的手绘 SVG 已在用户会话-30 的验收返修中移除；人物头像与 QQ秀仍为游戏人物的矢量图。

### 真实图标来源

`public/period-assets/icons/sources.json` 记录每组图标的原始地址、SHA-256 摘要、原生尺寸及必要的裁切说明。图标替换同时覆盖桌面、开始菜单、任务栏、标题栏与应用内共用入口。

- Windows 7：来自 [Visnalize 原系统图标资源存档](https://github.com/Visnalize/resources/tree/main/icons/win7)，包含 `imageres.dll`、`iexplore.exe`、`shell32.dll`、`Journal.exe` 的图标。保留原生帧，选择同尺寸的 32 位真彩资源，不使用 4 位或 8 位兼容帧。虚构校园应用使用原版文件夹、文档、收藏与系统工具图标。
- 开始按钮：来自 [Windows 7 原版按钮素材](https://github.com/EJSnow/Windows-7-skin)，使用 100% 与 150% 两种像素密度的原始三态条图，普通、悬停、按下状态各自对应原图区域。
- QQ：采用[公开保留的经典企鹅透明原图](https://zjc.wtu.edu.cn/images/qq-1.png)，原始 584×584 像素，仅去除透明边距；另核对[腾讯官网企鹅图](https://qzonestyle.gtimg.cn/qzone/qzact/act/external/tiqq/logo.png)。排除白底图片，保留原有透明通道，未重绘轮廓。
- QQ空间：[官网六代页面原始标识](https://qzonestyle.gtimg.cn/qzone_v6/proj_qzonelogin/img/qzone-login-logo.32@2x.png)，仅从完整图片裁出星形标识，不重绘形状或字母。
- 人人网：[历史蓝红标识](https://upload.wikimedia.org/wikipedia/en/4/41/Renren.png)，仅裁出左侧图形标识，替换上一版错误的蓝绿小人图。
- 英雄联盟：[Riot 官方经典标识原图](https://cmsassets.rgpub.io/sanity/images/dsfx7636/news_live/d468cbc16c555d790f90e9cda9cc58761b83980b-240x240.png)，240×240 像素，逐字节保留；16 像素标题栏图取自[国服原 favicon](https://lol.qq.com/favicon.ico)。排除后来圆形 L 标识与粉丝制作的艾希图标。
- 多玩盒子：[历史软件原标识](https://p.e5n.com/up/2018-8/20188221054578140.png)，48×48 透明图，替换上一版错误的棕色方盒重绘。

原图和历史程序图标可具有不同分辨率，不将放大后的文件冒称为高清原图。当前官网、资源存档或镜像的访问/更新时间不单独证明图标在 2012 年的发布日期；本阶段按旧截图中的标识结构核对，不把下载站页面年份当作完整安装包版本证据。

软件名称、标识和引用图像的相关权利归原权利方。项目是大学生活模拟游戏，不提供真实 Windows 桌面、QQ/人人账号服务或 Riot 客户端连接。

## 离线与兼容

构建时递归收集静态文件并按文件内容计算缓存版本，确保新增头像、装备、原画和壁纸也能断网显示。更新缓存时保留 localStorage 游戏进度，已有缓存的页面会切换到新版本；首次访问不主动刷新页面。

既有 v1 存档仍可读取；对局中新加的英雄 ID 是可选元数据，缺省时按旧状态展示默认英雄，不改变已保存的结果。人物日记和收藏不会被错误展示为其他 NPC 的公开内容。
